# LEON - Solo Website 🎸

Site oficial do artista **LEON - Solo** - Rock de Raiz Universal.

## 🚀 Sobre o Projeto

Site desenvolvido para apresentar o trabalho do artista LEON - Solo, fusionando a alma do pop-rock nacional com a potência do rock internacional.

## 🛠️ Tecnologias

- HTML5
- CSS3 (Grid & Flexbox)
- JavaScript (ES6+)
- Git para controle de versão

## 📦 Como Usar

1. Clone o repositório
2. Abra `index.html` no navegador
3. Ou use `npm run dev` para servidor local
